# Bone Cancer Classification 🦴🔬

## 📌 Overview

This project uses **Deep Learning, YOLO, and Computer Vision** to classify bone X-ray images into trained categories using an interactive Streamlit web application.

The application allows users to upload an X-ray image and view the model's predicted class and confidence score.

**Disclaimer:** This project is for educational and research purposes only. It is not a substitute for professional medical diagnosis.

## ✨ Features

- Bone X-ray image classification
- Deep Learning-based prediction
- Image upload through Streamlit
- Predicted class and confidence score
- Interactive web interface using `app.py`
- Image processing with OpenCV

## 🛠️ Technologies Used

- Python
- YOLO
- Ultralytics
